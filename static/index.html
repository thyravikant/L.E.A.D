    How scoring works

    Visual confidence cv is the geometric mean of the OCR word confidences in the row. Semantic confidence cs is the weighted pass rate of the validation rules (a failed hard rule sets it to 0). Joint confidence is C = cvα · cs1-α. A row is auto-accepted only if C ≥ 0.80 and no rule scores below 0.5; everything else goes to a person.
